# Obsidian XNU Port

Experimental XNU/Darwin porting project for Redmi Note 14 Pro 4G (MediaTek MT6789).

## Structure

- tools/obsidian-port — platform analysis and adapter scripts
- tools/dt-converter — Linux FDT to Apple ADT conversion tools

## Status

Experimental research. No successful XNU boot on the target device yet.

## Safety

Device firmware, boot images, private identifiers and raw memory dumps are not included.
